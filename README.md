This project is a **Machine Learning + Streamlit web app** that predicts **carbon credits required** based on yearly emissions data of companies.  
## 🚀 Features
- 📊 Upload and analyze company-wise emission data  
- 🤖 Predict **carbon credits** using a trained ML model  
- 📈 Visualize emissions trends with interactive charts  
- 🌐 Easy-to-use Streamlit dashboard
